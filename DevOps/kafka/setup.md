## Kafka local setup with Docker with Conduktor
- Conduktor is a GUI tool to manage Kafka cluster.

- git clone https://github.com/conduktor/kafka-stack-docker-compose.git
- Open Project: 
  - docker compose -f full-stack.yml up
  - docker compose -f full-stack.yml down
- Open Conduktor: http://localhost:8080

- Connect to kafka container to use CLI commands.
